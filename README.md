# LinkSnip - URL Shortener

A full-stack URL shortener built with **Node.js, Express, MongoDB and EJS**, styled with **Tailwind CSS**. Users can sign up, log in, turn long URLs into short links, and see how many times each link was clicked.

## Features

- User signup and login with hashed passwords (`bcryptjs`)
- Authentication with JWT stored in an `httpOnly` cookie
- Create short links (8-character IDs generated with `nanoid`)
- Public redirect: anyone with a short link can open it, no login needed
- Click tracking with a timestamp for every visit
- Per-user dashboard showing only your own links
- Analytics endpoint that only the link owner can read
- Input validation: invalid URLs are rejected, and `https://` is added when missing
- Error handling: bad IDs and duplicate emails show a message instead of crashing the server
- Responsive UI with copy-to-clipboard buttons

## Tech Stack

| Part | Technology |
|---|---|
| Server | Node.js, Express 4 |
| Database | MongoDB with Mongoose |
| Views | EJS |
| Styling | Tailwind CSS v4 |
| Auth | JWT (`jsonwebtoken`), `bcryptjs`, `cookie-parser` |
| Short IDs | `nanoid` v3 |
| Dev tool | `nodemon` |

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- [MongoDB](https://www.mongodb.com/try/download/community) running locally, or a free [MongoDB Atlas](https://www.mongodb.com/atlas) cluster

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Create a `.env` file** in the project root
   ```env
   PORT=8001
   MONGODB=mongodb://localhost:27017/short-url
   JWT_SECRET=replace-this-with-a-long-random-string
   ```
   The app will not start without `JWT_SECRET`.

4. **Create `src/input.css`** (if it does not exist) with this one line
   ```css
   @import "tailwindcss";
   ```

5. **Run the app.** Use two terminals:
   ```bash
   # Terminal 1: server
   npm run dev

   # Terminal 2: Tailwind (rebuilds public/styles.css when you edit views)
   npm run dev:css
   ```

6. Open **http://localhost:8001**

### Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Starts the server with nodemon (auto-restart) |
| `npm run dev:css` | Builds Tailwind CSS and watches for changes |
| `npm run build:css` | One-time minified CSS build (use before deploying) |
| `npm start` | Starts the server with plain Node (production) |

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `JWT_SECRET` | Yes | Secret used to sign login tokens. Use a long random string |
| `MONGODB` | No | MongoDB connection string. Defaults to `mongodb://localhost:27017/short-url` |
| `PORT` | No | Server port. Defaults to `8001` |
| `NODE_ENV` | No | Set to `production` to make the login cookie `secure` (HTTPS only) |

## Routes

### Pages

| Method | Path | Access | Description |
|---|---|---|---|
| GET | `/` | Logged in | Dashboard with your links |
| GET | `/login` | Public | Login page |
| GET | `/signup` | Public | Signup page |

### Auth

| Method | Path | Description |
|---|---|---|
| POST | `/user` | Create an account (`name`, `email`, `password`) |
| POST | `/user/login` | Log in (`email`, `password`) and set the cookie |
| GET | `/user/logout` | Clear the cookie and redirect to login |

### Links

| Method | Path | Access | Description |
|---|---|---|---|
| POST | `/url` | Logged in | Create a short link (`url`) |
| GET | `/url/:shortId` | Public | Redirect to the original URL and record a click |
| GET | `/url/analytics/:shortId` | Owner only | JSON with `totalClicks` and the visit history |

Example analytics response:

```json
{
  "totalClicks": 3,
  "analytics": [
    { "timestamp": 1793000000000 },
    { "timestamp": 1793000100000 },
    { "timestamp": 1793000200000 }
  ]
}
```

## Security Notes

- Passwords are hashed with bcrypt and never stored in plain text.
- The login token is stored in an `httpOnly`, `sameSite=lax` cookie, so browser JavaScript cannot read it.
- Never commit your `.env` file. It is listed in `.gitignore`.
- Analytics can only be read by the user who created the link.

## Deployment

1. Use a hosted database such as MongoDB Atlas and put its connection string in the `MONGODB` variable.
2. Set `JWT_SECRET` and `NODE_ENV=production` on your host.
3. Build command: `npm install && npm run build:css`
4. Start command: `npm start`

Make sure `tailwindcss` and `@tailwindcss/cli` are listed under `dependencies` in `package.json`, or commit the built `public/styles.css`, so the build step works on the host.
