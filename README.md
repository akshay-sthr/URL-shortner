# URL Shortener

A simple URL shortener built using Node.js and Express.js. It takes a long URL and generates a shorter link that can be used to redirect users to the original website.

## About the Project

I built this project to practice backend development with Node.js and Express. While working on it, I got to understand how routes work, how requests are handled, and how a short URL can be used to redirect a user to another page.

## Tech Stack

- Node.js
- Express.js
- EJS
- JavaScript
- HTML and CSS
- MongoDB (if used in this project)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/akshay-sthr/URL-shortner.git
```

Move into the project directory:

```bash
cd URL-shortner
```

Install the dependencies:

```bash
npm install
```

Create a `.env` file in the root directory and add the environment variables required by the project.

Start the server using the command configured in `package.json`. For example:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser if your application is running on port 3000.
